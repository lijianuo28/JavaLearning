# <center>智能外卖订餐系统（AI增强版）· 项目整理</center>

## 一、项目简介

基于Spring Boot的外卖订餐平台，包含用户端和管理端，支持点餐、订单管理、AI智能问答等功能。功能在持续开发中...

## 二、技术栈

-- **后端框架**：Spring Boot、MyBatis-plus

-- **数据库**：MySQL

-- **缓存**：Redis

-- **中间件**：WebSocket

-- **AI服务**：阿里通义千问API

-- **工具**：Git、Maven

## 三、核心模块

### 管理端

-- 员工登录与管理

-- 菜品管理（增删改查、起售停售）

-- 订单状态管理和定时处理

-- 数据统计

### 用户端

-- 登录/注册（JWT + 微信登录）

-- 菜品浏览与查询

-- 购物车管理

-- 下单

-- 订单查询

-- AI智能问答

### AI 智能客服

-- 接入阿里通义千问API

-- 暂时支持两种意图：

	- 查询菜品：“今天有什么菜”
	- 查询订单：“我的订单到哪了”

-- 通过System Prompt控制回答范围

## 四、技术亮点

### 4.1 接口控制权限

- JWT 生成 token
- 拦截器校验登录状态
- 区分用户端和管理端权限

### 4.2 Redis 缓存优化

- 菜品列表查询量较大
- 使用 Redis 缓存热点数据
- 降低数据库查询压力

### 4.3 WebSocket 实时推送
- 用户下单 → 商家端实时收到通知
- 用户催单 → 商家端实时收到提醒

### 4.4 AI 智能问答
- 接入阿里通义千问 API
- 解析自然语言意图
- 返回对应业务数据

## 五. 遇到的困难 & 解决方案
### 困难 1：AI 回答不相关的问题
- **现象**：用户问“我的外卖到了吗”，AI 可能聊别的话题
- **解决**：设计 System Prompt，限定回答范围只在外卖场景内

### 困难 2：Redis 缓存与数据库一致性问题
- **现象**：菜品更新后，缓存还是旧数据
- **解决**：更新数据库后，主动删除 Redis 缓存，下次查询时重新加载
